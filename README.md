# 📖 منصة القرآن الكريم | Quran Audio Platform

منصة استماع إلكترونية متكاملة للقرآن الكريم والأذكار المأثورة، تعتمد على API الموثق من [mp3quran.net](https://www.mp3quran.net) و [hisnmuslim.com](https://hisnmuslim.com)، وتتيح تصفح واستماع وتحميل تلاوات السور والقراء بروايات مختلفة مع السبحة الإلكترونية التفاعلية.

---

## ✨ المميزات الرئيسية

- **فهرس السور الشريفة**: تصفح 114 سورة مع إمكانية التصفية (مكية / مدنية) والتصفح برقم الصفحة والآيات.
- **دليل القراء والروايات**: تصفح أكثر من 241 قارئاً مع دعم المصاحف والروايات المتعددة (حفص، ورش، قالون، الدوري...).
- **البحث العربي الذكي**: محرك بحث يدعم إزالة التشكيل وتوحيد الهمزات والألفات.
- **مشغل صوتي مركزي ثري**:
  - مشغل ثابت أسفل كافة صفحات المنصة.
  - إمكانية تقديم وترجيع 10 ثوانٍ، التحكم بالسرعة (0.75x إلى 2x)، التشغيل التلقائي تالياً (Auto-Next)، وكتم الصوت.
  - واجهة خاصة كاملة وموسّعة للهواتف الذكية (Full Mobile Overlay).
- **نظام التحميل المباشر**: تحميل ملفات MP3 مباشرة باسم منظم وإظهار نسبة التحميل (%) real-time.
- **قسم الأذكار والسبحة الإلكترونية**:
  - سبحة رقمية تفاعلية مع حفظ العدادات والجوائز المأثورة.
  - أذكار الصباح والمساء وأدعية حصن المسلم المأثورة.
